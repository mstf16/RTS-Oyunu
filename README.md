### 1. Project Context & Purpose
This Real-Time Strategy (RTS) game was developed using **VIBE CODING** tools. The development process utilized local and free tier AI models, including:
* **Local AI:** Qwen 2.5 3B
* **Gemini API:** Free Gemini Flash models
* **Ollama Cloud:** Free Gemma models
* **Claude:** Free Claude Sonnet (low usage tier)

The core purpose of this project is to achieve a highly optimized RTS game without relying on high-end hardware or premium/commercial subscription-based AI tools with large token capacities.
